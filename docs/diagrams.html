Generated UML

Processing Sequence

sequenceDiagram
  actor User
  participant DesktopApp
  participant Loader
  participant Chunker
  participant OllamaProvider
  participant Verifier
  participant Categorizer
  participant ProductionMap
  User->>DesktopApp: Choose design text and start generation
  DesktopApp->>Loader: Load and normalize source text
  Loader-->>DesktopApp: Clean document text
  DesktopApp->>Chunker: Split document into chunks
  Chunker-->>DesktopApp: Chunk list
  loop For each chunk
    DesktopApp->>OllamaProvider: Summarize chunk with local model
    OllamaProvider-->>DesktopApp: Generated summary
    DesktopApp->>Verifier: Validate summary
    Verifier-->>DesktopApp: Accept or fallback
    DesktopApp->>Categorizer: Classify useful content
    Categorizer-->>DesktopApp: Production category
  end
  DesktopApp->>ProductionMap: Assemble categorized notes
  ProductionMap-->>User: Markdown production map

Shows the core user-to-output workflow without exposing private prompt details.

Chunk Lifecycle

stateDiagram-v2
  [*] --> Loaded
  Loaded --> Chunked
  Chunked --> SubmittedToModel
  SubmittedToModel --> Verified
  SubmittedToModel --> FallbackNeeded
  FallbackNeeded --> Verified
  Verified --> Categorized
  Categorized --> AddedToProductionMap
  AddedToProductionMap --> [*]

Shows how a raw text chunk becomes useful production-map material.

Production Map Assembly

flowchart TD
  A[Design Document] --> B[Load Text]
  B --> C[Chunk Content]
  C --> D[Summarize Locally]
  D --> E{Response Valid?}
  E -->|Yes| F[Categorize]
  E -->|No| G[Fallback Summary]
  G --> F
  F --> H[Group By Production Category]
  H --> I[Write Markdown Production Map]
  I --> J[Reviewable Planning Artifact]

Shows the product-level transformation from raw design text to an organized planning artifact.
