Setup

1. Install Ollama

Install Ollama from the official download page, then make sure it is running before launching the demo.

Open Ollama download

2. Pull Phi-3

Open PowerShell or Terminal and download the model used by this demo.

ollama pull phi3

3. Open AYO

Unzip the demo package, launch ayo.exe, load the bundled sample if needed, and click Generate Map.

Double-click ayo.exe

First load may take a little longer while Ollama starts and the local model wakes up.

Successful Run

A successful test loads the source note into the left panel and generates a Markdown production map in the right panel with sections for Characters, World and Lore, Abilities, Story, and Uncategorized Review.

The app keeps the workflow simple: open the sample, generate the map, then save the Markdown output if you want a file copy.

If the demo says it cannot connect to Ollama, open Ollama first, wait a few seconds, then click Generate Map again.
