# AYO Chat Agent v1 Showcase

This repository is the public showcase for **AYO Chat Agent v1**.

AYO Chat Agent v1 is a local AI-assisted desktop tool that turns rough game design notes into structured production maps through a controlled Ollama and Phi-3 workflow.

## What is public here

- GitHub Pages portfolio site
- case study pages
- diagrams and video evidence
- downloadable Windows demo package

## What stays private

- full source code
- tests and development workflow
- private implementation notes
- deeper integration and future agent logic

## Boundary

This repo is meant to be **hireable proof**, not a full public source release.

The working implementation lives in a separate private repository. This public repo exists so recruiters, collaborators, and reviewers can quickly understand the product direction, test the packaged demo, and evaluate the project without exposing the full recipe.
